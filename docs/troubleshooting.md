# 🔧 トラブルシューティング

[READMEへ戻る](../README.md) · [English](en/troubleshooting.md)

よくある問題と解決方法をまとめます。

## ❌ マイクダイアログが表示されない

- 症状：「記録開始」を押してもマイクアクセス許可画面が出ない
- 解決策
  1. ブラウザーのURL付近のマイクアイコン🎤をクリック
  2. 「このサイトで常に許可」を選択
  3. ページをリロード（F5キー）して再試行

## ❌ 音量が「--.- dBFS」のままで変化しない

- 症状：マイクアクセスは許可されているが音量が計測されない
- 解決策
  1. 画面の状態表示を先に見る。「マイクが供給元で無音化されています」と出ていれば、ブラウザーより手前で無音が流されている（通話の割り込みなど）
  2. マイクが正しく接続されているか確認
  3. システムの音量設定でマイクがミュートになっていないか確認
  4. 他のアプリケーションがマイクを占有していないか確認
  5. ブラウザーを再起動して再試行

## ❌ 記録が自動的に停止する

- 症状：放置していると記録が勝手に止まる
- 解決策
  1. 画面上部の計測エンジンの表示を見る。「簡易モード」と出ている場合、描画が止まると記録も止まる。HTTPSで開き直すとAudioWorkletが使える
  2. 「マイクが切断されました」と出ている場合は、記録中にデバイスを失っている。何行目までが有効かはその場に出る（そこまでのログは書き出せる）
  3. 省電力モード・スリープモードを無効化する
  4. ブラウザーの自動タブ停止機能を無効化する。⚠**タブが破棄されるとログは全部消える。**長時間記録では、こまめにCSVへ書き出しておく

## ❌ 「計測エンジン：簡易モード（欠測の可能性あり）」と出る

- 症状：高精度モードにならない
- 原因：AudioWorkletのモジュール（`worklet/meter-processor.js`）を読み込めていない
- 解決策
  1. `file://`で直接開いていないか確認する。ローカルで試すなら`python -m http.server 8000`などでHTTP経由にする
  2. ブラウザーがAudioWorkletに対応しているか確認する

## ❌ CSVの`hash`列が空になる

- 症状：ハッシュチェーンの値が出ない
- 原因：`crypto.subtle`は安全なコンテキストでしか使えない。`http://192.168.1.10:8000/`のような、httpsでないホスト名やIPアドレスつきのURLで開くと使えない
- 解決策：https、`localhost`、`file://`のいずれかで開き直す
- ⚠**`file://`はこの症状の原因ではない。**`file://`は安全なコンテキストなのでハッシュは出る（Chromiumで実測）。`file://`で起きるのは上の「簡易モード」のほうである

## ❌ 「マイクを20秒以内に取得できませんでした」と出る

- 症状：記録開始を押したあと、待たされて失敗する
- 原因：マイクの許可プロンプトが放置されている（20秒で時間切れにして、画面が固まらないようにしている）
- 解決策：許可プロンプトに応答してから、もう一度記録開始を押す

## ❌ グラフに線が出ない・途切れる

- 症状：記録しているのにグラフが空に見える、または線が途中で切れている
- 確かめること
  1. 記録していない時間：線をつながない。停止して再開すると、そのあいだは空く（つなぐと、測っていない時間を測ったように見えるため）
  2. 無音の区間：下端に張り付く。線は出ているが、最下段の目盛りと重なって見えにくい
  3. 表示下限より静かな音：表示下限（既定-110dBFS。`?bands=off`では-90dBFS）より静かな音も下端でそろう。これは表示のための設定であり、CSVに記録される値は動かない。超音波帯の小さな変化（数dB）は、大きな数字の下の「超音波帯（直近◯秒の区間）」の数字で読む
  4. 画面上部の「計測エンジン」が簡易モードで、かつタブが背面にあると、描画も記録も止まる
- ブラウザーのズーム（110%・133%など）やスマートフォン幅でも、グラフは描ける。キャンバスの大きさは、`getBoundingClientRect()`が返す非整数の幅を整数に直してから決めるので、`RangeError: Invalid array length`にはならない（ズームやスマートフォン幅で非整数になった幅6件を`test/canvas.test.js`が確かめている）。グラフが真っ黒になるなら、ズームとは別の原因である

## ❌ スマートフォンで設定を変えられない

- 症状：ログ間隔や表示下限を変えたいが、設定の項目が見えない
- 解決策：画面上部の「設定を表示」を押す。狭い画面では設定が畳まれた状態で始まる
- 「CSV書き出し」と「統計リセット」が見当たらないときは、記録開始（停止）の右の「その他」を押す。幅480px以下では、この2つを「その他」にまとめている
- 幅320〜414pxで「起動→ログ間隔1秒→記録→停止→CSV」まで通ることを確かめている。ただしこれはデスクトップのChromiumで画面幅を再現したものであり、実機ではない（[README](../README.md)の「ブラウザー対応状況」）
