# ✨ 主な機能（詳しい説明）

[READMEへ戻る](../README.md) · [English](en/features.md)

[README](../README.md)の「✨ 主な機能」の要点を、画面の見え方と記録の中身まで含めて詳しく説明します。CSVの列と書式は[CSVの資料](csv.md)、計測の作りは[計測の資料](measurement.md)にあります。

## 画面の表示（数字・グラフ・帯域）

- **リアルタイム音量可視化**  
  Web Audio APIを用いて、マイク入力の音量（dBFS）を即時にグラフ化・数値表示。グラフの横軸は実時間（直近60秒）で、目盛りとラベルが入る。折れ線はCSVに記録される区間そのものを描くので、画面の描画が止まってもグラフに穴があかない。記録していない時間と、音が1つも届かなかった区間（欠測）は線をつながず、デジタル無音の区間は下端に張り付く。超音波帯（18〜22kHz）の値を破線で重ね、凡例はグラフの下に置く（色と線の形の両方で見分けられる）。⚠**画面の大きな数字は直近2048サンプル（48kHzで約43ミリ秒。サンプルレートで変わる）の全帯域のRMSで、高精度モードのCSVの`dbfs`（区間全体のエネルギー平均）とは窓が違う。**ときどき大きくなる音（扇風機のうなり・洗濯機など）では、エネルギー平均が大きな瞬間に引っぱられるので、大きな数字のほうがCSVの値より低く見える時間が長くなる。簡易モードでは、CSVの`dbfs`も記録した瞬間のこの窓の値である。
- **超音波帯（18〜22kHz）の記録と表示**  
  区間ごとに、超音波帯（18,000〜22,000Hz）と可聴帯（20〜18,000Hz）のエネルギーを記録する（CSVの帯域の列）。画面では、超音波帯の値をグラフの破線と統計の「超音波帯の最大」に出す。大きな数字の下には「超音波帯（直近1秒の区間）：-91.7 dBFS」のように、最後に記録した区間の値（CSVの`band_ultra_dbfs`と同じ。区間の長さはログ間隔）を数字で出す。大きな数字とは窓も帯域も違う。数dBの小さな変化はグラフでは読みにくいので、この数字で読む。最初の区間が届くまでは`--.- dBFS`、値のない区間では「（この区間は値なし）」、`?bands=off`・簡易モード・超音波帯を測れないサンプルレートでは値の代わりに理由が出る。⚠**帯域の値は「その帯域に音のエネルギーがあったか」の記録で、何の音かは分からない。**超音波帯の値がない区間（簡易モード・`?bands=off`・計算に使えるフレームがない区間）は破線を切る。凡例の下には、記録を始めると「この端末で記録できる上限：約◯◯kHz」が出る。AudioContextとマイクの音声トラックのサンプルレートの、小さいほうの半分である（トラックが報告しないときはAudioContextの半分で、「トラックの値は不明」と添える）。サンプルレートで決まる上限で、マイクがその高さの音を拾えることは示さない。注意書きには、帯域の有効率（`band_valid_ratio`）が1.0を下回った区間の件数と最小値、マイクとAudioContextのサンプルレートの食い違い（変換で、上限に近い高い音が低く記録される）、超音波帯を測れないサンプルレート、`?bands=off`で帯域の計算を止めていること、簡易モードで帯域を計算していないこと、を出す。`?bands=off`を付けて開くと帯域の計算を止め（帯域あり・なしで有効サンプル率を比べるためのもの）、凡例と注意書きに「止めています」と出る。超音波帯の線を描かないとき（`?bands=off`・簡易モード・超音波帯を測れないサンプルレート）は、凡例の見本の線を隠し、描かない理由を出す。

## 記録と統計

- **欠測のない記録（AudioWorklet）**  
  区間の集計をオーディオスレッドで行うため、画面の描画が止まっても記録は続く。CSVの1行が1区間に対応する。AudioWorkletを読み込めない環境は簡易モードへ自動的に切り替わる。
- **統計情報の自動算出**  
  稼働時間、ログ件数、平均・最大・最小音量、変動幅、サンプルピーク、超音波帯の最大を自動計算・表示。平均はエネルギー平均（Leqと同じ定義）で、母集団はCSVの行と一致する（音が1つも届かなかった区間＝`dbfs`が空欄の行は除く）。**平均の重みは行数ではなく区間長（秒）である。**ログ間隔は記録中に変えられるため、1秒の区間と3秒の区間を同じ重みで平均すると実時間に比例しない値が出る。CSVから同じ値を出す手順は[CSVの資料](csv.md)の「Excel/Google Sheetsでの分析手順」にある。停止→再開の境界では、`timestamp`の差に休止時間がまるごと入る。その行（トレーラーの`# sessionStartAt=`）だけは差を使わず、`# intervalSec=`のログ間隔を重みにする。「超音波帯の最大」は`band_ultra_dbfs`の最大で、デジタル無音の行に付いた帯域の値も数える（[CSVの資料](csv.md)の「帯域の列」）。簡易モードと`?bands=off`では測れないため`--.-`のままになる。
- **記録の穴の有無を、両側で表示**  
  クリップした区間があれば区間の数と延べサンプル数を、有効サンプル率が1.0を下回った区間があれば件数と最小値を、その場で画面に出す。クリップは単発と連続を言い分ける。3サンプル以上続いた区間は波形がつぶれて値が本来の音と違い、1〜2サンプルの単発なら区間の値への影響は小さい。記録した全サンプルに対する割合も出す（延べの数だけでは大ごとに見えるため）。穴がないときも「記録の穴なし（クリップ0区間／有効サンプル率は10区間すべて1.000）」と出す。片側だけ出すと、記録がきれいなときに画面が何も言わないので、利用者は「穴がない」と「まだ調べていない」を区別できない。簡易モードの行はどちらも測れないため、その区間数を添えて「測れません」と出す。

## 記録の中身とCSV

- **録音なしのプライバシー配慮**  
  音声そのものは保存せず、音量データのみを扱う。CSP（`connect-src 'none'`）により、外部への送信をブラウザーの機能として止めている。
- **CSVログ出力（v3）**  
  タイムスタンプ付き音量データに、区間の通し番号・ピーク・クリップ数・有効サンプル率・帯域の値（超音波帯18,000〜22,000Hzと可聴帯20〜18,000Hz）・ハッシュを添えて書き出す。帯域の値は「その帯域に音のエネルギーがあったか」の記録で、何の音かは分からない。測定条件は`#`から始まるメタ行に残る。
- **破損・欠落の検出（ハッシュチェーン）**  
  各行のハッシュに前の行のハッシュを混ぜる。CSVがそのまま渡ってきたときに、うっかりの破損・部分的な欠落・順序の入れ替わりを見つけられる。⚠**意図的な改変には、相手が誰であっても耐えない**（鎖の作り方を公開しているので、書き換えたあとに計算し直せば検証は通る。[CSVの資料](csv.md)の「ハッシュチェーンで何が分かるか」）。
- **無音も記録に残す**  
  デジタル無音は`-Infinity`として1行残す。行を落とさないので「活動がなかった」ことを示せる。音が1つも届かなかった区間（欠測）は、`dbfs`を空欄にして無音と分ける。
- **マイクの切断・時刻の跳びの検出**  
  記録中にマイクを失ったら記録を止め、何行目までが有効かを画面に出す。供給元で無音化された場合（通話の割り込みなど）とAudioContextの中断で時刻がずれた場合も、その場で画面に出す。
- **測定条件の記録と警告**  
  マイク側の音の加工（AGC・ノイズ抑制・エコーキャンセル）を無効で要求したうえで、実際にどうなったかを`getSettings()`の実値で確かめる。加工が有効なままなら「この記録のdBFSは絶対値として扱えない」と画面に出す。デバイス名・サンプルレート・加工の状態はCSVのメタ行にも残る。

## 操作と表示の設定

- **マイク取得の取り消し**  
  許可ダイアログを放置しても画面は固まらない。20秒で時間切れになり、接続中でも「停止」でその場で取り消せる。
- **リアルタイム設定変更**  
  ログ間隔（1s/3s/5s/10s/1mプリセット対応）と表示下限は記録中でも変更可能で即座に反映。表示下限は表示のための設定であり、記録される値は動かない。表示下限の既定は-110dBFSで、`?bands=off`で開いたときは-90dBFSである。静かな部屋の超音波帯は-90dBFSより低いことがあり、表示下限が-90では超音波帯の破線が下端に張り付くため。
- **データ累積記録**  
  「記録開始⇒停止⇒記録開始」を繰り返しても、統計とログデータは累積され続ける（「統計リセット」で手動クリア可能。記録を停止してから押せ、ログ・統計・グラフ・注意書きをまとめて消す）。ただしログはブラウザーのメモリーにしかなく、タブを閉じると消える。
- **マルチデバイス対応**  
  PC・タブレット・スマートフォンの画面幅に合わせたレスポンシブデザイン（実機で確かめたのはiPhone 18 Pro Maxの1台だけで、Androidは確かめていない。詳しくは[README](../README.md)の「ブラウザー対応状況」）。記録開始と停止は同じ場所に出し、そのとき押せるほうだけを見せる（マイクに接続中は「停止」で取り消せる）。幅480px以下では「CSV書き出し」と「統計リセット」を「その他」にまとめ、記録開始／停止・「その他」・ヘルプ・テーマの切り替えを1行に並べる（「その他」はEscキーでも閉じられる）。
- **即起動・事前準備不要**  
  ページを開き、マイクアクセスを許可するだけで動作開始。インストール不要のWebアプリ。
- **直感的なユーザーインターフェイス**  
  大型数値表示・カラーメーター・リアルタイムグラフ・ヘルプ機能により、専門知識不要で利用可能。
- **ダークモード・ライトモード対応**  
  環境に応じてテーマを切り替え可能（設定は自動保存）。
- **日本語・英語の表示の切り替え**  
  ヘッダーの右上のボタン（日本語の表示では`EN`、英語の表示では`JA`）で、画面の文言（ボタン・統計・注意書き・状態の表示・ヘルプ・ツールチップ・読み上げ用の説明）を日本語と英語で切り替える。最初の言語は、URLの`?lang=ja`／`?lang=en` → ボタンで選んで保存した言語 → ブラウザーの言語（`navigator.languages`の先頭が日本語なら日本語、それ以外は英語）の順で決まる。記録中に切り替えてもよく、記録・統計・グラフ・ハッシュチェーンは変わらない（変わるのは表示だけ）。CSVの中身と書き出すファイル名は、言語によらず同じである。使い方は[README](../README.md)の「表示の言語を切り替える」にある。
